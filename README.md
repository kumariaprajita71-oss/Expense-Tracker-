# Expense Tracker

A simple console-based expense tracker written in Java. Record what you spend, view all your expenses with the total, and delete entries, all from the terminal.

## Features
- Add an expense with a description and amount
- View all expenses along with the total 
- Delete an expense by its number
- Menu-driven, so it keeps running  until you exit

## Concepts Used
- Array of objects to store the expenses
- `Scanner` for user input
- Loops and conditionals (`while`, `for`, `if-else`)
- class and objects (`Expense`) 
## How to Run
1. Clone the repository:`https://github.com/kumariaprajita71-oss/Expense-Tracker-.git.`
2. Compile:`javac Expensetracker.java`
3. Run: `java Expensetracker`
